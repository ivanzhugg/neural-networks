## Запуск

Использовался Python 3.12. Создание окружения и установка библиотек в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "Lab 2.1\Result\requirements.txt"
```

Открыть нужный `Result/student.ipynb` в редакторе с поддержкой Jupyter, выбрать Python из `.venv`, перезапустить ядро и выполнить ячейки сверху вниз.

Данные читаются из соседней папки `Task/data`, поэтому сохраняется структура каталогов. Результаты Lab 2.1 и Lab 2.2 записываются в `Result/artifacts`. Для выполнения достаточно CPU.

Все три готовых ноутбука выполнены сверху вниз и прошли встроенные и дополнительные проверки. Использование ИИ указано в ноутбуках.
