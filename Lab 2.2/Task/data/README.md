# Данные ЛР2

Каталог содержит два набора данных для тематического блока «Табличные данные».

- `titanic.csv` — самостоятельная работа практики A.
- `clients.csv`, `transactions.csv`, `mcc_codes.csv`, `transaction_types.csv` — синтетический транзакционный набор практики B.

## Транзакционный набор

Данные сформированы специально для курса и не зависят от legacy-файлов исходной версии. Генератор с фиксированным `SEED=42` хранится на teacher-стороне в `teacher/02_tabular_data/make_transaction_data.py`.

Смысл строк:

- `clients.csv`: одна строка = один клиент; 5000 клиентов;
- `transactions.csv`: одна строка = одна операция; 100000 операций;
- `mcc_codes.csv`: одна строка = один MCC-код;
- `transaction_types.csv`: одна строка = один тип операции.

В данных намеренно есть две особенности для учебных проверок:

1. часть клиентов не имеет ни одной транзакции — это делает выбор `left`/`inner` значимым при построении feature table;
2. 400 транзакций имеют `mcc_code=9999`, отсутствующий в справочнике — это позволяет увидеть `left_only` после `merge` и обработать неизвестную категорию явно.

Суммы операций положительные. Направление денежных средств (`expense`/`income`) задаётся таблицей `transaction_types.csv`, а не знаком `amount`.
